# Supplier and geometry evidence

Supplier reference review: 2026-09-13. Existing repository assets were identified by the user as their intended catalogue. Imported geometry is hashed in the evaluated model where implemented; matching an asset to a product does not confirm every mounting/interface requirement.

| Item                                      | Primary source                                                                                    | Evidence and limits                                                                                                                                                                                   |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Wolweiss AST03003004, 30 × 30, four slots | [Reiman Portugal](https://reiman.pt/pt/ast03003004-aluminium-profile-30x30-4-slots/)              | Manufacturer/product identity, nominal section and cut-to-length availability; actual end section comes from the retained supplier STEP. Requested cutting tolerance still needs supplier acceptance. |
| Wolweiss AST03006006, 30 × 60, six slots  | [Reiman Portugal](https://reiman.pt/pt/ast03006006-aluminium-profile-30x60-6-slots/)              | Retained design reference. Do not substitute it for a 30 × 30 part without updating geometry, interfaces and order dimensions.                                                                        |
| Wolweiss CBR3030 angle bracket            | [Reiman Portugal](https://reiman.pt/pt/wlw-cbr3030-cbr3030-30x30-bracket/)                        | Retained supplier STEP. Installed orientation, fasteners and access need confirmation.                                                                                                                |
| Wolweiss GLR3030 hinge                    | [Reiman Portugal](https://reiman.pt/pt/wlw-glr3030-glr3030-30-30-removable-long-hinge/)           | Prior design selection; exact v3 mounting, load suitability and motion interfaces remain unresolved.                                                                                                  |
| Shapeoko 5 Pro                            | [Carbide 3D assembly manual](https://my.carbide3d.com/pdf/shapeoko5pro_assembly_2.pdf)            | User confirms original 5 Pro 4×4. Spindle/router, dust shoe and full moving envelope must match the actual machine.                                                                                   |
| Current machine specification page        | [Carbide 3D](https://carbide3d.com/shapeoko/shapeoko5pro-specs/)                                  | Page now describes 5.1 Pro. V3 does not treat those dimensions as confirmed for the user's original 5 Pro.                                                                                            |
| Constraint solver                         | [CadQuery assembly documentation](https://cadquery.readthedocs.io/en/latest/assy.html)            | Numerical constraints solve placements. Measured residuals and independent solid checks remain necessary.                                                                                             |
| Geometry kernel                           | [OpenCascade BRepCheck](https://occt3d.com/dev/doc/refman/html/class_b_rep_check___analyzer.html) | Shape validity is evidence about topology/geometry, not physical assembly or structural certification.                                                                                                |

No supplier cutting/processing tolerance, hardware load rating, panel-retention detail or glass suitability is inferred merely from a product name. Missing evidence blocks final order release. Quotation packs request the needed confirmation and preserve candidate dimensions for discussion.
